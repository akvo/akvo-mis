# Additions to the vendored LDNOOBW list (issue #511, QA follow-up).
#
# Ours, not vendored: picked by hand from better_profanity's bundled
# wordlist (https://github.com/snguyenthanh/better_profanity), keeping
# only words that are profane or a slur in every reading this product
# is likely to meet. Not copied wholesale, because that list refuses
# words this platform's customers use -- `hiv`, `gay`, `urine`,
# `menstruation`, `tampon`, `foreskin`, `stroke`, `paddy`, `dong`.
#
# Plurals are matched by the code, so only the singular is needed.
# A line with spaces is a phrase: it matches those words joined by
# hyphens or run together, never the words on their own.
#
# Spellings a subdomain cannot carry (`f.u.c.k`, `sh!t`) are left out.
