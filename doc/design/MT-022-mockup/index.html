Platform admin console

Static mockups for MT-022 (console UI) and MT-023 (inspection). Open any file directly in a browser — no build step, no server.

These use the tokens already in frontend/src/variables.scss: Poppins, $blue #1651b6, the white 86 px header, $bg-page #f0f2f5, 6 px radius, round buttons. Nothing here proposes a new design language, and the console is built from the same antd components control-center already uses.

Artboards are fixed at desktop width. They do not reflow, because a responsive console is not something this design commits to yet.

Tenants

The landing page. One row per workspace with the counts from the single-query summary endpoint. Note that Inspect is greyed out for the suspended and deleted rows — their hosts no longer resolve, so the link would open a 404.

MT-022 §4

Tenant detail

Counts, the people in the workspace, the entitlement switches and the danger zone. A deactivated user's row says how many of their devices are blocked, because that consequence is the point of the action and is otherwise invisible.

MT-022 §5

Rename dialog

The impact is stated as live counts fetched for this workspace, not as a generic warning. Confirming needs both the typed subdomain and a successfully loaded preflight.

MT-022 §6 · MT-021 §5

Operators

List, invite and revoke. The page says where the first operator comes from, because nobody can invite themselves and the empty state on a fresh deployment otherwise reads as a bug.

MT-022 §7 · MT-021 §8

Inspecting

A workspace's own app during a read-only inspection, with the workspace switcher open. The banner is the only thing inspection adds — everything below it is the workspace's own layout and components, unchanged.

MT-023 §9
Two screens deliberately absent. There is no sign-in mockup: the console reuses the app's existing /login page unchanged, served on the admin host, so drawing it would only invite someone to redesign it. There is no switch-flow diagram either — it compared two options, and the banner switcher shown on Inspecting is the one that was chosen.
